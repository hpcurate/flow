## What was done

### `--flow-session=<name>`
- CORE 0.13.0's FLOW box (Ctrl+Alt+F) has three tabs: a timer (FLOW's `--flow-timer`, as before), a view
  (`--flow-view`, as before) and a **session**: `FLOW.exe --flow-session=<name>`.
- FLOW starts an open focus session by that name in the pill, with the pill's usual goal and breaks.
- One already open is ended first; an end files it, as always, when it had a minute of focus.
- While TUTOR or GRIND is linked, it waits underneath, as an open session does.
- The pill comes up if it was off.
- A running FLOW hears it as a second instance; a closed FLOW starts with it.
