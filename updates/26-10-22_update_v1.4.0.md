## What was done

### Where it was (`r261022-z257`)
- **The cause:** `win-state.json` kept the right place, but a saved place counted only if it fitted a monitor's *work area*. CORE's bar is an AppBar that takes the top of its monitor out of the work area (240 px, or 56 for the minimal bar). Hugo's standard view was saved at y = −1376 on the top monitor, just under the minimal bar: with the bigger bar up, it was "off screen", so FLOW opened in the middle of the main monitor. Only a CORE layout put it back.
- **Now** (`homeOf`, `fitIn`): a saved place belongs to the monitor holding most of it, by the monitor's bounds; it comes back there, moved just enough to be in that monitor's work area (smaller only if it has to be). Standard, minimal and mini all do it. A monitor that's gone still lands on the main one.
- **The pill:** it was found by its display id alone, and Windows renumbers monitors (a restart, a cable). It now also keeps the monitor's bounds (`pos.db`): the id, else the same bounds, else its own point, else the main monitor; found under a new id, it keeps that one.

### Full screen below CORE's bar (`r261022-7fzl`)
- On a monitor whose top is kept (its work area starts lower than its top), full screen is now a plain window over the monitor **minus that band**, still FLOW's full-screen view. It follows the band when it changes (bar ⇄ minimal bar ⇄ line, or given back). Already in Windows' full screen when a band appears, it steps below it.
- A monitor with a free top (the main one, whose taskbar is at the bottom) keeps Windows' own full screen, as before. *Claude's choice:* the rule is "whatever keeps the top of that monitor", so it works wherever CORE's bar sits (on Hugo's PC today it is on the main monitor, 210 px).

### Views from CORE (`r261022-ec85`, FLOW's half)
- `FLOW.exe --flow-view=standard|minimal|mini|fullscreen|pill`: a running FLOW hears it as a second instance, a closed one opens with it. The window switches the way its own buttons do, so each view opens where it was last; full screen goes to the monitor it was last used on; `pill` shows or hides the pill.
